# Text edition: v2 (for review on the text-v2 branch)

Duel rules unchanged: all numbers come from `play/rules.js`.

- **Opponent read** (from round 3): counts only moves actually played in the last 4 rounds.
- **Decided by**: one sentence on the result screen. On a knockout it describes the final round; when time runs out, the round with the biggest swing.
- **Replay code**: lists your choices in order. "Replay code" on the result screen, or `?replay=CODE`, plays the game again and confirms an identical result. This proves there's no hidden randomness.
- **Rules (`?`)**: the text is generated by calling the functions in `rules.js`, so it can't drift from the code.
- **Zone duel preview** at `?duel=zones` (not decided): 5 zones, 1 hit + 2 adjacent blocks, no shield.
  - Logic comes from `sim/zones-core.js`, shared with `sim/zones.mjs`.
  - The Easy bot loops head, head, chest. The Hard bot reads your last 6 picks.
- **Easy bot and the golden race**: the Easy bot skips the race when both apes' fruit adds up odd. There's no randomness, so testers see both outcomes and replays still match. The Hard bot always races.

Smoke test: `node text/smoke.mjs http://localhost:8765/` (serve the repo root).
